# Open Source Standards

Holds the open-source evaluation backlog, the approved allowlist and the recorded
decisions for Helix Research Labs platform engineering.

- `backlog.json` - categories queued for evaluation (one `status` per category).
- `approved/allowlist.json` - projects that are cleared for internal use.
- `decisions/` - one JSON record per evaluated category.

Evaluations follow policy OSS-POL-2.4. Only categories whose `status` is
`pending` are processed in a cycle.
